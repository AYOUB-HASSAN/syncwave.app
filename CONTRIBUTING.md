# Contributing to SyncWave

First off, thank you for considering contributing to SyncWave! It's people like you that make open-source software such a great community to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub. Include as much detail as possible:
* Steps to reproduce the bug
* Expected behavior vs actual behavior
* Your operating system and browser version
* Any relevant console errors or logs

### Suggesting Enhancements
We welcome new ideas! If you have a feature request or an enhancement idea, please create an issue explaining:
* The problem your idea solves
* How it should work
* Any alternatives you've considered

### Pull Requests
We actively welcome pull requests. Here is the process:

1. **Fork the repository** and create your branch from `main`.
2. **Set up the development environment** by following the setup instructions in the `README.md`.
3. **Make your changes**. If you've added code that should be tested, add tests.
4. **Ensure your code lints** and formatting looks consistent with the rest of the project.
5. **Issue that pull request!** Include a clear description of what you've done.

## Project Structure

* `/frontend` - Contains the React UI and Vite configuration.
* `/backend` - Contains the Express server, Socket.io logic, and media serving.
* `/desktop-app` - Contains the Electron wrapper and packager configuration.
* `/Landing-page` - Contains the vanilla HTML/CSS/JS marketing landing page.

Thank you for contributing!
